# 🌿 植物养护记录小程序

一个记录植物生长、养护、环境与纪念的微信小程序。数据全部保存在本机（无需后端），用微信开发者工具导入即可运行。

## 一、导入与运行

1. 下载本项目文件夹（或解压 `plant-recorder.zip`）。
2. 打开【微信开发者工具】（下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html ）。
3. 点击 **导入项目**，目录选择本文件夹。
4. AppID 选择 **测试号**（项目已默认填 `touristappid`，可直接用游客模式预览）。
5. 导入后点击 **编译** 即可在模拟器中运行。

> 说明：本项目使用 `wx.chooseMedia` / `wx.saveFile` 处理图片，真机调试即可正常拍照上传。

## 二、功能总览

| 模块 | 说明 |
| --- | --- |
| 主页 | 植物图片墙（每株以图片卡片显示）、总投入金额统计、今日需浇水 / 逾期待办统计、近期待办列表 |
| 植物信息 | 名称、品种、状态、价格、购买途径、种植形式、所在位置、购买日期、陪伴起始、备注、照片 |
| 生长环境 | 自定义环境分类（如阳台直射、半阴散射光），每个环境单独设置**光照强度（lux 勒克斯）**与**每日光照时长（小时/天）**，附 lux 参考表 |
| 种植形式 | 水苔、土培、水培、板植、颗粒 |
| 养护记录 | 可无限添加：**浇水、施肥、修剪、换盆、防治病虫害、测量**，每条可附文字与照片，形成时间线 |
| 提醒 | 浇水 / 施肥 / 换盆 三种提醒，按季节自动频率，也可为每株植物单独设置间隔天数 |
| 纪念碑 | 植物「送人」或「去世」时建立纪念碑，记录日期、纪念语与陪伴时长，可随时恢复为活跃植物 |

## 三、提醒机制（重点）

### 浇水频率（默认按季节自动）
- **春（3-5月）**：每 **10** 天
- **夏（6-8月）**：每 **5** 天
- **秋（9-11月）**：每 **10** 天
- **冬（12-2月）**：每 **15** 天

### 自定义间隔
- 浇水间隔：留空 = 按季节自动；也可填自定义天数覆盖。
- 施肥间隔：默认 30 天，可自定义。
- 换盆间隔：默认 365 天，可自定义。

### 到期计算方式
从该植物**最近一次对应类型的养护记录日期**（浇水→最近一次浇水、施肥→最近一次施肥、换盆→最近一次换盆）起算下一周期；若无记录则从陪伴起始 / 购买日期起算。主页与提醒页会展示“还有 N 天 / 今天到期 / 逾期 N 天”。

> ⚠️ 关于“推送通知”：微信小程序**无法在后台主动推送**（需要后端 + 订阅消息模板，且需认证主体）。本小程序以**打开即见的到期提醒**方式实现：主页统计今日需浇水、逾期项，提醒页汇总全部待办。若你需要手机横幅推送，需要后续接入微信「订阅消息」+ 云函数后端，可另行沟通。

## 四、数据与存储

- 所有数据存在微信本地缓存（`wx.setStorageSync`），卸载或清除缓存会丢失，请留意。
- 图片通过 `wx.saveFile` 保存到本地用户目录，重启不丢失。
- 数据结构：
  - `plants`：植物数组（含 records 养护记录、自定义间隔、纪念标记）
  - `envs`：环境分类数组（名称 / lux / 光照时长）
  - `memorialPlants`：纪念碑数组（送人 / 去世）

## 六、小提示

- 状态字段预设：健康 / 生长中 / 休眠 / 状态一般 / 需要关注 / 生病中。
- 首页统计的“总投入”自动累加所有活跃植物的价格。
- “陪伴时间”从陪伴起始日期（默认等于购买日期）自动计算。

## 七、需求对照

| 需求 | 实现 |
| --- | --- |
| 记录植物生长 | 每株独立档案，可无限添加养护记录形成时间线 |
| 购买途径 + 价格 | 记录购买途径（花市/花店/网购/赠送等）与价格，主页自动统计总投入 |
| 生长环境分类 | 自定义环境（阳台直射/半阴散射光等），每个环境单独设置光照强度 lux + 光照时长（小时/天），附 lux 参考表 |
| 植物以图片显示在主页 | 主页为图片卡片墙，无照片时显示占位图标 |
| 每株可添加笔记 | 每条记录可附文字 + 照片 |
| 护理类型 | 修剪、换盆、浇水、防治病虫害、施肥、测量 六类 |
| 种植形式 | 水苔、土培、水培、板植、颗粒 |
| 植物字段 | 名称、品种、状态、价格、种植方式、位置、照片、陪伴时间、购买时间 |
| 纪念碑 | 送人 / 去世 可建立纪念碑（记录日期、纪念语、陪伴时长），可恢复为活跃植物 |
| 养护记录 | 可不停添加 |
| 浇水施肥换盆提醒 | 春/秋 10 天、夏 5 天、冬 15 天自动，也可为每株单独设置间隔天数 |
