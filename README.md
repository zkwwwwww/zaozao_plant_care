# 植早早

一个记录植物生长、养护、环境与纪念的微信小程序。数据全部保存在本机（无需后端），用微信开发者工具导入即可运行。

## 一、导入与运行

1. 下载本项目文件夹（或解压 `plant-recorder.zip`）。
2. 打开【微信开发者工具】（下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html ）。
3. 点击 **导入项目**，目录选择本文件夹。
4. AppID 已填 `wx0a6ce3c13d086a96`，导入后直接使用该小程序即可。
5. 导入后点击 **编译** 即可在模拟器中运行。

> 说明：本项目使用 `wx.chooseMedia` / `wx.saveFile` 处理图片，真机调试即可正常拍照上传。账号登录使用云开发环境 `prod-d2gc40g65b4fc0f07`，配置在 `config/env.js`。

### 本地质量检查

电脑安装 Node.js 18 或更高版本后，在项目根目录执行：

```bash
npm run check
```

该命令会检查 JavaScript 语法、JSON 配置、WXML 标签结构，并运行日期与提醒算法单元测试。微信专用 API、样式和真机图片权限仍需在微信开发者工具中验证。

## 二、功能总览

| 模块 | 说明 |
| --- | --- |
| 主页 | 植物图片墙（每株以图片卡片显示）、总投入金额统计、今日需浇水 / 逾期待办统计、近期待办列表，并简略显示登录状态 |
| 账户 | 底部最右栏。授权填写微信头像和昵称，云函数按当前微信绑定账号；可更新资料或退出本机登录 |
| 植物信息 | 名称、品种、状态、价格、购买途径、种植形式、所在位置、购买日期、陪伴起始、备注、照片 |
| 生长环境 | 自定义环境分类（如阳台直射、半阴散射光），每个环境单独设置**光照强度（lux 勒克斯）**与**每日光照时长（小时/天）**，附 lux 参考表 |
| 种植形式 | 水苔、土培、水培、板植、颗粒 |
| 养护记录 | 可无限添加：**浇水、施肥、修剪、换盆、防治病虫害、测量**，每条可附文字与照片，形成时间线 |
| 提醒 | 浇水 / 施肥 / 换盆 三种提醒，按季节自动频率，也可为每株植物单独设置间隔天数 |
| 纪念碑 | 植物「送人」或「去世」时建立纪念碑，记录日期、纪念语与陪伴时长，可随时恢复为活跃植物 |

## 三、提醒机制（重点）

### 浇水频率（默认按季节自动）
- **春（3-5月）**：每 **10** 天
- **夏（6-8月）**：每 **5** 天
- **秋（9-11月）**：每 **10** 天
- **冬（12-2月）**：每 **15** 天

### 自定义间隔
- 浇水间隔：留空 = 按季节自动；也可填自定义天数覆盖。
- 施肥间隔：默认 30 天，可自定义。
- 换盆间隔：默认 365 天，可自定义。

### 到期计算方式
从该植物**最近一次对应类型的养护记录日期**（浇水→最近一次浇水、施肥→最近一次施肥、换盆→最近一次换盆）起算下一周期；若无记录则从陪伴起始 / 购买日期起算。主页与提醒页展示未来 14 天内的近期任务，逾期任务始终展示，文案为“还有 N 天 / 今天到期 / 逾期 N 天”。提醒页点击“完成”会进入养护记录页并自动选中对应类型。

> ⚠️ 关于“推送通知”：微信小程序**无法在后台主动推送**（需要后端 + 订阅消息模板，且需认证主体）。本小程序以**打开即见的到期提醒**方式实现：主页统计今日需浇水、逾期项，提醒页汇总全部待办。若你需要手机横幅推送，需要后续接入微信「订阅消息」+ 云函数后端，可另行沟通。

## 四、数据与存储

- 植物、环境和纪念数据仍存在微信本地缓存（`wx.setStorageSync`），卸载或清除缓存会丢失。云端目前只保存账号资料。
- 账号身份以云函数读取的微信 `OPENID` 为准，不使用客户端自报的用户 ID。头像和昵称由用户在账号页确认后写入 `users` 集合。
- 图片通过 `wx.saveFile` 保存到本地用户目录，重启不丢失。账号头像上传到云存储，数据库只保存 `fileID`。
- 多张图片会等待全部本地持久化操作结束后再写入植物档案；失败图片不会写入临时路径，可重新选择上传。
- 数据结构：
  - `plants`：植物数组（含 records 养护记录、自定义间隔、纪念标记）
  - `envs`：环境分类数组（名称 / lux / 光照时长）
  - `memorialPlants`：纪念碑数组（送人 / 去世）

## 六、小提示

## 九、开发者工具冒烟检查

每次提交前至少检查：

1. 首页、环境、提醒三个 Tab 以及植物详情、植物编辑、记录编辑、环境编辑、纪念碑共 8 个页面可打开。
2. 空数据时，首页、环境、提醒和记录区域显示对应原创插画。
3. 连续选择多张植物照片后立即保存，所有成功照片均按选择顺序保留；失败时可看到明确提示。
4. 提醒页点击浇水、施肥或换盆的“完成”，记录页自动预选对应类型；保存后到期日后移。
5. 删除正在使用的环境后，植物回到未分类；建立纪念后从主页和提醒中移除，恢复后重新出现。
6. 无效植物链接、已删除纪念对象和图片失败均有可见反馈。

## 十、账号登录

所有页面的数据读取和写入都要求登录有效。启动时读取本机登录缓存，有效期 7 天；未登录、已退出或缓存过期时，任何页面都会先跳到「账户」栏的登录引导，不读取植物、环境或纪念数据，也不调用云函数。登录成功后回到首页，默认环境分类也在这时才写入。微信已不再提供一次性弹窗来读取真实头像和昵称，因此登录分两步：

1. 云函数 `login` 读取当前微信身份，并在 `users` 集合中创建或更新该用户。客户端不能指定别人的用户 ID。
2. 用户点头像授权选择微信头像或相册图片，在昵称框点选微信昵称或自行填写，再点「授权登录」。

退出登录只清除本机保存的头像、昵称和登录状态，本地植物数据保留，重新登录后恢复显示。云端账号仍绑定这台微信。

首次登录前，请在微信开发者工具或云开发控制台完成：

1. 在开发者工具中展开 `cloudfunctions/login`，右键选择「上传并部署：云端安装依赖」。命令行部署目前识别不到这个环境，不要用命令行代替这一步。
2. 打开 `users` 集合，权限设为「仅创建者可读写」。云函数首次登录时会尝试创建该集合。
3. 在小程序公众平台填写用户隐私保护指引，声明昵称、头像和选中的照片。未声明时，头像选择和相册会被微信拦截。
4. 云存储需允许登录用户上传 `avatars/` 目录。

当前只有一个云环境 `prod-d2gc40g65b4fc0f07`，还没有单独的开发环境。植物、记录和环境数据尚未迁移到云端，不会和本地数据双写。
